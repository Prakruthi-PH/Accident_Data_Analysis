# Accident Data Analysis

## Project Overview
Analyzed road accident data to understand accident characteristics and identify patterns related to accident severity.

## Problem Statement
To analyze road accident data and understand how factors such as road conditions, junctions, weather, lighting, speed limits, vehicles, and time are associated with accident severity.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SQL
- Power BI

## Python — EDA
- Performed basic data exploration and statistical analysis.
- Checked data types, missing values, and duplicate records.
- Cleaned and prepared the dataset for analysis.
- Analyzed numerical and categorical variables.
- Used visualizations to explore accident patterns and relationships.

## SQL Analysis
- Used SQL to analyze accident records.
- Applied filtering, grouping, sorting, and aggregate functions.
- Analyzed accident severity, casualties, vehicles, road types, weather conditions, and other categories.

## Power BI Dashboard
- Created a simple interactive dashboard.
- Used KPI cards to display important metrics.
- Added visuals to present accident patterns.
- Added slicers to filter and explore the data.

## Key Insights
- Summarized important patterns identified during the analysis.
- Compared accident characteristics across different categories.
- Identified factors associated with accident severity.
